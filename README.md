# 📰 Fake News Detection

A Machine Learning project that detects whether a news article is **Real** or **Fake** using Natural Language Processing (NLP) and classification algorithms.

## 🚀 Features

- Detects fake and real news
- Preprocesses text data
- Trains a Machine Learning model
- Predicts news category
- Evaluates model performance

## 🛠️ Technologies Used

- Python 3
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## 📚 Python Concepts Used

- Data Preprocessing
- Data Analysis
- Machine Learning
- Text Processing
- Model Training
- Model Prediction

## ▶️ How to Run

1. Install Python 3.
2. Install the required libraries:

```bash
pip install pandas numpy scikit-learn matplotlib seaborn
```

3. Run the project:

```bash
py fake_news_detection.py
```
